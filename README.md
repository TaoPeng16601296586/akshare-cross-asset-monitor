# 大类资产数据监测与另类固收投资判断数据基座

## 项目定位

本项目旨在搭建一个面向中国金融市场的 **大类资产数据监测与另类固收投资判断数据基座**。

当前阶段的核心目标不是直接生成投资建议，而是先建立一个稳定、客观、可追溯的数据底层，用于持续监测权益、债券、商品、外汇和宏观经济环境，并为未来另类固收资产的投资研究、市场判断和 AI 智能分析提供基础输入。

项目后续希望服务于以下场景：

- 票据
- ABS
- REITs
- 非标及其他低流动性固收资产
- 固收+及大类资产配置
- 资产配置与交易策略辅助判断
- AI Agent 投资研究与投委会辅助

这些资产往往缺乏像股票市场一样统一、高频、标准化的交易数据，因此更加依赖对宏观环境、利率市场、资金面、风险偏好和跨资产价格变化的综合判断。

因此，本项目首先构建一个统一的市场事实层。

# 二、为什么先做数据基座

项目的核心原则是：

> 在进行 AI 分析、投资判断和预测之前，必须先保证事实层的数据质量。

金融投资场景中，AI最大的风险之一并不是模型不会分析，而是输入数据错误、口径不一致或者时间错位。

因此，本项目当前阶段重点解决以下问题：

- 数据是否真实存在
- 数据是否最新
- 数据日期是否正确
- 数据单位是否明确
- 数据统计口径是否清晰
- Raw 数据与 Processed 数据是否一致
- 不同数据源之间是否具有可比性
- 是否能够与 Wind 或官方数据进行交叉验证

# 三、数据来源

当前项目主要通过 AKShare 获取公开金融市场数据。

AKShare 本身并不是数据生产方，而是对多个公开数据源的接口封装。

当前涉及的数据源包括：

- 中证指数有限公司
- 新浪财经
- 东方财富
- 同花顺
- 申万指数
- 中国货币网
- 国家外汇管理局
- 上海证券交易所
- 深圳证券交易所
- 商品期货交易所公开数据
- 宏观经济公开数据平台

项目原则上优先使用：

> 官方数据源 > 官方指数公司 > 交易所 > 中国货币网 > 主流金融数据平台

Wind 主要作为外部专业数据库进行交叉验证。

# 四、数据质量原则

项目不会为了保证 Dashboard “看起来完整”而生成或者填补不存在的数据。

以下原则是项目的底线。

## 1. 不伪造缺失数据

如果某个公开接口无法稳定获取：

- 保持为空
- 显示待补
- 不使用模型预测填充
- 不使用其他不同口径数据强行替代

---

## 2. 不混淆金融指标定义

例如：

### FDR007 不等于 DR007

FDR007 是存款类机构质押式回购定盘利率。

DR007 是存款类机构质押式回购加权成交利率。

二者不能互相替代。

---

### ETF基金份额变化不等于ETF资金净流入

ETF基金份额变化主要反映一级市场份额变化。

而二级市场“主力净流入”等指标属于成交资金分类。

两者必须分开展示。

---

### 商品持仓变化不等于资金流入

期货持仓量的增加只代表市场参与和未平仓合约变化。

不能直接解释为多少亿元资金进入市场。
